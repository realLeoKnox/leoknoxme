02 / HOW I THINK

我更在意，
一个结论怎样成立。

把孤立的问题放回系统里，追问因果，也给新证据留下位置。
思考不是一次定论，而是不断往前的一轮循环。

  1. 01观察与分析
  2. 02归纳规律
  3. 03提炼本质
  4. 04迁移应用
  5. 05实际验证
  6. 06持续修正
  7. 07带着反馈，再来一轮

分清事实与观点。找到根因。新证据出现时，愿意调整原来的判断。

05 / THINGS I VALUE

一些我想坚持的事。

不必句句像宣言，但希望能在做选择时记得。

01 / TRUTH

事实先于立场

先弄清发生了什么，再决定如何评价。

02 / INDEPENDENCE

保留独立判断

不因为流行或权威，就省略自己的思考。

03 / VERIFICATION

相信证据，保留不确定

能验证的尽量验证，无法确认的就不装作确定。

04 / OPENNESS

开放探索，保持自主

珍视开放技术、信息交流与个人数字自主。

05 / GROWTH

允许出错，也持续修正

承认偏差，理解原因，让反馈进入下一轮。

06 / RESPECT

尊重时间与有效沟通

重视回应、守信与真正有内容的交流。

07 / PRAGMATISM

让技术服务实际需要

考虑成本、稳定性与效果，不为复杂而复杂。
