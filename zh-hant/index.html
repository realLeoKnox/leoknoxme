01 / A LITTLE ABOUT ME慢慢認識

認真與有趣，
都算是我的一部分。

有時追著一個問題研究到底，
有時只是想看看，一個離譜的點子能有多好玩。

?01

喜歡追問，也喜歡動手。

不只想知道是什麼，還想弄清為什麼。先探索、試驗、看結果，再回來修正想法。

好奇心，需要一點行動
◎02

結論再好聽，也想看看依據。

不會因為答案來自權威或 AI 就直接接受。事實、推斷和猜測，我希望分清楚。

獨立判斷，允許修正
✳03

認真起來認真，整活也不含糊。

喜歡玩梗、調侃和天馬行空的想像。嚴謹與幽默可以同時存在，探索本身也應該有意思。

也有一點抽象精神
02 / HOW I THINK

我更在意，
一個結論怎樣成立。

把孤立的問題放回系統裡，追問因果，也給新證據留下位置。
思考不是一次定論，而是不斷往前的一輪循環。

  1. 01觀察與分析
  2. 02歸納規律
  3. 03提煉本質
  4. 04遷移應用
  5. 05實際驗證
  6. 06持續修正
  7. 07帶著回饋，再來一輪

分清事實與觀點。找到根因。新證據出現時，願意調整原來的判斷。

03 / MY LITTLE PATTERNS

在數位生活之外，
也留意日常的節奏。

研究工具，記錄變化，
也享受一些小小的體驗。

try. adjust. try again. ↗
01

記錄、比較，再回顧。

願意保留資料與重要過程，比較不同時間的變化，用記錄理解長期趨勢。

02

讓工具按自己的方式工作。

喜歡研究、設定和改造數位環境。重視透明、可設定，也希望保有自主選擇的空間。

03

觀察狀態，也調整節奏。

健身時記錄訓練、觀察狀態；生活裡，也會為了更適合自己的體驗做一點調整。

04

給純粹有趣的事留點時間。

一杯合口味的咖啡、一段漂亮的影片、一次有意思的聊天，不需要很大的理由。

05 / THINGS I VALUE

一些我想堅持的事。

不必句句像宣言，但希望能在做選擇時記得。

01 / TRUTH

事實先於立場

先弄清發生了什麼，再決定如何評價。

02 / INDEPENDENCE

保留獨立判斷

不因為流行或權威，就省略自己的思考。

03 / VERIFICATION

相信證據，保留不確定

能驗證的盡量驗證，無法確認的就不裝作確定。

04 / OPENNESS

開放探索，保持自主

珍視開放技術、資訊交流與個人數位自主。

05 / GROWTH

允許出錯，也持續修正

承認偏差，理解原因，讓回饋進入下一輪。

06 / RESPECT

尊重時間與有效溝通

重視回應、守信與真正有內容的交流。

07 / PRAGMATISM

讓技術服務實際需要

考慮成本、穩定性與效果，不為複雜而複雜。
